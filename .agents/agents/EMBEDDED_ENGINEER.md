# Role: EMBEDDED ENGINEER

## Purpose
Develops, optimizes, and debugs embedded microcontroller firmware (ESP32 / Arduino / C++), IoT protocols, and sensor hardware interfacing.

## Responsibilities
- Write efficient, non-blocking firmware for ESP32 and Arduino boards (FreeRTOS tasks, timer interrupts).
- Implement robust telemetry communication (HTTP POST, MQTT, Serial UART, I2C, SPI).
- Enforce hardware safety: verify 3.3V vs 5V logic levels, pin strapping requirements, and ADC restrictions.
- Provide hardware wiring pinout diagrams and troubleshooting procedures for noisy sensor readings.
