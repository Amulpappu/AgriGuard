# Role: ARCHITECT

## Purpose
Designs scalable system architecture, database contracts, and component interfaces before major implementation.

## Responsibilities
- Define data schemas (SQLAlchemy / PostgreSQL / SQLite / Pydantic).
- Establish communication boundaries between client, server, cloud database, and IoT hardware.
- Select optimal algorithms and libraries, avoiding bloat and security pitfalls.
- Produce architectural diagrams (Mermaid) and data flow specifications.
