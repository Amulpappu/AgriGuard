AGRIGUARD IoT FIELD SENSOR WIRING DIAGRAM

ESP32 DevKit V1 (30-Pin) • DHT22 Temp/Humidity • Capacitive Soil Moisture Sensor v1.2

Exact Wire-by-Wire Map
  • 🔴 3.3V POWER (RED)
    ESP32 3V3 → Breadboard (+) Rail → Powers DHT22 VCC & Soil VCC.
  • ⚫ GROUND (BLACK / GRAY)
    ESP32 GND → Breadboard (−) Rail → DHT22 GND & Soil GND.
  • 🟡 GPIO 4 (PIN D4) — DHT22 DATA
    ESP32 Pin D4 (GPIO 4) connects to DHT22 Pin 2 (DATA).
  • 🟤 10kΩ PULL-UP RESISTOR
    Bridges between DHT22 DATA (Pin 2) and 3.3V (+) Rail for bus stability.
  • 🔵 GPIO 34 (PIN D34) — SOIL AOUT
    ESP32 Pin D34 (GPIO 34 / ADC1) connects to Soil Sensor AOUT.
Pin Distinction Check:
• D4 (GPIO 4) = Top header pin for DHT22 (Yellow Wire)
• D34 (GPIO 34) = Bottom header pin for Soil Probe (Blue Wire)
