1. Open your **Figma Desktop app** or [figma.com](https://figma.com) in your browser.
2. Create a new blank design file (or open an existing one).
3. Open your file explorer at:
   `c:\Users\lohit\Downloads\AgriGuard\docs\figma\`

## 🎨 Method 2: Import Complete Canvas via Figma Plugin

If you want the entire side-by-side interactive canvas with zoom controls, swatches, and components:
1. In Figma, click the **Resources** icon (Shift + I) &rarr; **Plugins**.
2. Search and run **"html.to.design"**.
3. Select **"Import HTML"** and choose:
   `c:\Users\lohit\Downloads\AgriGuard\docs\figma\AgriGuard_Figma_Canvas.html`
4. The plugin will convert the entire canvas, mockups, design tokens, and components into structured Figma frames.

## 📦 Method 3: Import Design Tokens & Colors

If you use **Tokens Studio for Figma** or Figma Variables:
1. Import **[`AgriGuard_Tokens.json`](file:///c:/Users/lohit/Downloads/AgriGuard/docs/figma/AgriGuard_Tokens.json)**.
2. All Obsidian, Emerald, Mint, Red, and Gold variables will populate into your Figma Local Variables collection automatically.
